12. Usuários, grupos e permissões

Controlar quem pode acessar arquivos, comandos e serviços.

Por que estudar este assunto?

Um sistema com vários usuários precisa impedir que qualquer pessoa leia, altere ou execute todos os arquivos. Contas e permissões aplicam o princípio do menor privilégio.

O que você vai aprender

✓ Compreender UID, GID e grupos
✓ Criar e modificar contas
✓ Interpretar permissões rwx
✓ Aplicar propriedade e privilégios mínimos

Conceitos fundamentais

UID

Identificador numérico do usuário.

GID

Identificador numérico do grupo.

r, w, x

Leitura, escrita e execução.

Dono

Usuário proprietário do arquivo.

Grupo

Conjunto de usuários com permissões comuns.

sudo

Execução controlada de comandos administrativos.

Explicação passo a passo

As permissões são avaliadas para dono, grupo e outros. Em `-rw-r-----`, o dono lê e escreve, o grupo lê e outros não acessam.

Alterar apenas `chmod` pode não resolver o problema se o proprietário estiver incorreto.

Contas usadas por serviços não devem ser usadas para login humano.

Comandos desta aula

ComandoPara que serve
idMostra UID, GID e grupos do usuário atual.
getent passwdConsulta contas conhecidas pelo sistema.
sudo useradd -m alunoCria usuário com diretório pessoal.
sudo groupadd projetoCria um grupo.
sudo usermod -aG projeto alunoAdiciona usuário ao grupo sem remover outros.
chmod 640 arquivoDefine leitura/escrita para dono e leitura para grupo.
sudo chown usuario:grupo arquivoAltera proprietário e grupo.

Demonstração no terminal

  1. Crie o grupoUse `sudo groupadd equipeweb`.
  2. Crie usuáriosAdicione dois usuários de laboratório.
  3. Associe ao grupoUse `usermod -aG`.
  4. Crie diretórioPrepare `/srv/projeto`.
  5. Aplique propriedadeDefina grupo e permissões.
  6. TesteAcesse usando cada conta e registre o resultado.

Prática guiada

Configure uma pasta em que membros de um grupo possam criar e editar arquivos, enquanto outros usuários não tenham acesso.
