13. Discos e sistemas de arquivos

Identificar discos, criar sistema de arquivos e configurar montagem persistente.

Objetivos

  • Identificar discos, criar sistema de arquivos e configurar montagem persistente.

Conteúdo essencial

  • Disco contém partições; partição pode receber sistema de arquivos.
  • Montagem associa um sistema de arquivos a um diretório.
  • /etc/fstab automatiza montagens e exige validação.

Referência rápida

ComandoFinalidade
lsblklistar dispositivos
blkididentificar UUID
df -huso montado
du -shuso por diretório
mountmontar

Comandos

lsblk -f
sudo fdisk -l
sudo mkfs.ext4 /dev/sdb1
sudo mount /dev/sdb1 /dados
sudo mount -a

Prática rápida

Adicione um disco virtual, formate, monte e valide leitura/escrita.

Desafio

Configure montagem por UUID sem impedir a inicialização.

Entrega

Saída de lsblk, linha do fstab e teste mount -a.
