15. Segurança, SSH e firewall

Proteger acesso remoto e limitar portas com firewall.

Objetivos

  • Proteger acesso remoto e limitar portas com firewall.

Conteúdo essencial

  • Atualizações, menor privilégio e redução de superfície são controles básicos.
  • Chaves SSH são preferíveis a senhas em administração.
  • Firewall deve liberar somente serviços necessários.

Referência rápida

ControleObjetivo
chave SSHautenticação forte
sudoelevação controlada
UFWfiltragem simples
logsauditoria

Comandos

ssh-keygen -t ed25519
ssh-copy-id usuario@servidor
sudo ufw default deny incoming
sudo ufw allow OpenSSH
sudo ufw enable
sudo ufw status verbose

Prática rápida

Configure acesso por chave e firewall permitindo apenas SSH.

Desafio

Desative login remoto direto do root e valide antes de encerrar a sessão atual.

Entrega

Configuração aplicada, portas abertas e teste de novo acesso.
