14. Rede e diagnóstico

Configurar e diagnosticar endereço, rota, DNS e portas.

Objetivos

  • Configurar e diagnosticar endereço, rota, DNS e portas.

Conteúdo essencial

  • Diagnóstico deve seguir camadas: interface, IP, rota, DNS e serviço.
  • Ping testa ICMP, não garante que uma aplicação esteja disponível.
  • ss mostra portas locais; curl testa aplicações HTTP.

Referência rápida

EtapaComando
interface/IPip -br a
rotaip route
DNSresolvectl query
porta localss -lntup
HTTPcurl -I

Comandos

ip -br a
ip route
ping -c 4 gateway
resolvectl query example.org
ss -lntup
curl -I http://localhost

Prática rápida

Diagnostique um cenário com IP válido, mas DNS indisponível.

Desafio

Elabore um roteiro de diagnóstico em no máximo oito passos.

Entrega

Roteiro e evidências de cada camada.
