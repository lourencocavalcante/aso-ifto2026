11. Gerenciamento de pacotes de software

Instalar, atualizar, consultar e remover programas usando repositórios.

Por que estudar este assunto?

Baixar programas de sites aleatórios dificulta atualização e verificação. Gerenciadores de pacotes usam repositórios confiáveis, resolvem dependências e registram o que foi instalado.

O que você vai aprender

✓ Diferenciar pacote e repositório
✓ Pesquisar e inspecionar pacotes
✓ Instalar e remover software
✓ Planejar atualizações

Conceitos fundamentais

Pacote

Arquivo com programa, metadados e instruções de instalação.

Repositório

Fonte organizada e assinada de pacotes.

Dependência

Componente necessário para outro programa.

APT

Ferramenta de alto nível em Debian e Ubuntu.

dpkg

Ferramenta de baixo nível para pacotes .deb.

Atualização

Substituição por versões mais recentes.

Explicação passo a passo

`apt update` não atualiza programas; ele atualiza a lista de versões disponíveis.

`apt upgrade` instala versões mais recentes dos pacotes já instalados.

Em servidores, atualizações devem ser registradas e testadas, principalmente quando afetam serviços Web ou bancos.

Comandos desta aula

ComandoPara que serve
apt search nginxPesquisa pacotes relacionados ao nginx.
apt show nginxMostra descrição e dependências.
sudo apt updateAtualiza os índices.

Demonstração no terminal

  1. PesquiseUse `apt search` para localizar um servidor Web.
  2. InspecioneLeia a descrição com `apt show`.
  3. InstaleExecute a instalação.
  4. ValideConfira serviço, processo e porta.
  5. Liste arquivosUse `dpkg -L` para descobrir configurações e documentação.

Prática guiada

Instale um servidor Web, identifique arquivo de configuração, diretório do site, serviço, processo e porta. Depois remova o pacote.
