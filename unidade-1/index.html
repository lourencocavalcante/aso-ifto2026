Unidade I — Fundamentos e instalação

Servidores, virtualização, Linux Server e Windows Server.

Aulas da unidade

01
01. Introdução aos sistemas de servidores

Entender o que é um servidor, como ele atende clientes e por que os serviços precisam ser administrados.

02
02. Virtualização e preparação do laboratório

Criar um ambiente seguro para instalar e testar servidores sem afetar computadores reais.

03
03. Instalação de um Linux Server

Instalar um servidor Linux mínimo, definir identidade, armazenamento, rede e atualização inicial.

04
04. Windows Server e PowerShell

Conhecer funções de servidor no Windows e executar tarefas básicas com PowerShell.

Como estudar esta unidade

  1. Leia o contexto antes dos comandos.
  2. Observe o diagrama e os conceitos.
  3. Reproduza a demonstração na VM.
  4. Execute a prática guiada.
  5. Responda à questão de revisão.
