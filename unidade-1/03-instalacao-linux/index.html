03. Instalação de um Linux Server

Instalar um servidor Linux mínimo, definir identidade, armazenamento, rede e atualização inicial.

Por que estudar este assunto?

Um servidor começa com uma instalação planejada. Escolhas feitas nessa etapa — como disco, usuário, rede e pacotes — influenciam segurança, manutenção e recuperação.

O que você vai aprender

✓ Planejar requisitos antes da instalação
✓ Compreender particionamento básico
✓ Definir hostname e usuário administrativo
✓ Atualizar e validar o sistema após instalar

Conceitos fundamentais

Distribuição

Conjunto formado pelo kernel Linux, utilitários, gerenciador de pacotes e políticas.

Partição

Divisão lógica do disco.

Sistema de arquivos

Estrutura usada para armazenar arquivos e diretórios.

Hostname

Nome pelo qual o servidor é identificado.

Usuário administrativo

Conta autorizada a usar sudo.

Instalação mínima

Instala somente componentes necessários.

Explicação passo a passo

Servidores geralmente usam instalações mínimas, pois cada pacote adicional aumenta consumo e superfície de ataque.

Em laboratório, um único sistema de arquivos é suficiente. Em produção, dados, logs e aplicações podem ser separados para reduzir impacto quando uma área cresce.

O servidor deve receber um nome claro, como `srv-web01`, e um endereço previsível para que clientes encontrem os serviços.

Demonstração no terminal

  1. Inicie pela ISOSelecione o idioma e o teclado.
  2. Configure armazenamentoUse o disco virtual e confirme o particionamento.
  3. Crie o usuárioUse uma senha forte e habilite administração com sudo.
  4. Defina o hostnameUse um nome que indique função e ordem.
  5. AtualizeApós o primeiro login, execute atualização e reinicie se necessário.
  6. Registre a baselineAnote versão, hostname, IP, disco e pacotes principais.

Prática guiada

Instale uma VM Linux Server. Após o primeiro acesso, produza um relatório com versão, hostname, IP, memória, disco e atualizações.
