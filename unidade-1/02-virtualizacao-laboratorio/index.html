02. Virtualização e preparação do laboratório

Criar um ambiente seguro para instalar e testar servidores sem afetar computadores reais.

Por que estudar este assunto?

Em administração de sistemas, erros fazem parte da aprendizagem. Uma configuração incorreta de rede ou disco pode inutilizar o sistema. Por isso, as práticas devem ocorrer em máquinas virtuais isoladas e recuperáveis.

O que você vai aprender

✓ Compreender máquina virtual e hipervisor
✓ Distinguir NAT, bridge e rede interna
✓ Criar snapshots com finalidade correta
✓ Organizar um laboratório de testes

Conceitos fundamentais

Máquina virtual

Computador simulado que possui CPU, memória, disco e rede virtuais.

Hipervisor

Software responsável por criar e executar máquinas virtuais.

Imagem ISO

Arquivo que representa a mídia de instalação do sistema.

Snapshot

Registro temporário do estado da máquina virtual.

NAT

Permite que a VM acesse a Internet usando a conexão do hospedeiro.

Rede interna

Conecta apenas as VMs do laboratório.

Explicação passo a passo

O hipervisor divide recursos do computador hospedeiro entre máquinas virtuais. Cada VM executa seu próprio sistema operacional.

Para as aulas, uma interface em NAT oferece acesso à Internet e uma interface em rede interna permite comunicação controlada entre servidor e cliente.

Snapshot serve para voltar rapidamente a um estado anterior durante testes. Ele não substitui cópia de segurança dos arquivos.

Demonstração no terminal

  1. Crie a VMDefina 2 CPUs, 2 a 4 GB de RAM e disco de 25 GB.
  2. Adicione a ISOSelecione a imagem do Linux Server.
  3. Configure a redeUse NAT na primeira interface e rede interna na segunda.
  4. Crie um snapshotFaça isso após a instalação e configuração inicial.
  5. TesteLigue cliente e servidor e use `ping` entre eles.

Prática guiada

Crie uma VM servidor e uma VM cliente. Configure uma rede interna e registre os endereços IP. Teste a comunicação nos dois sentidos.
