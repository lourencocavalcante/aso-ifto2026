04. Windows Server e PowerShell

Reconhecer funções do Windows Server e executar administração básica em PowerShell.

Objetivos

  • Reconhecer funções do Windows Server e executar administração básica em PowerShell.

Conteúdo essencial

  • Roles adicionam serviços; features adicionam capacidades auxiliares.
  • PowerShell trabalha com objetos e permite automação consistente.
  • A administração remota reduz acesso físico e melhora rastreabilidade.

Referência rápida

ElementoExemplo
RoleWeb Server, File Services, AD DS
FeatureBackup, Failover Clustering
CmdletGet-Service, Get-NetIPAddress

Comandos

Get-ComputerInfo
Get-Service
Get-NetIPAddress
Get-Volume
Get-WinEvent -LogName System -MaxEvents 20
