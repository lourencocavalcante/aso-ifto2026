04. Windows Server e PowerShell

Reconhecer componentes do Windows Server e executar administração inicial com PowerShell.

Objetivos da aula

Compreender os conceitos centrais.
Executar comandos ou configurações com segurança.
Diagnosticar falhas básicas.
Registrar evidências da prática.

Sequência didática

Licenciatura em Computação
1. Problematização

Apresente uma situação real de escola, laboratório ou sistema institucional relacionada a 04. Windows Server e PowerShell.

2. Fundamentação

Explore os conceitos essenciais e conecte-os ao funcionamento do sistema operacional.

3. Demonstração

Execute os comandos passo a passo, verbalizando hipótese, resultado esperado e forma de validação.

4. Prática orientada

Os estudantes reproduzem o procedimento em ambiente isolado, registrando evidências.

5. Sistematização

Compare resultados, discuta erros e produza uma síntese técnica coletiva.

6. Avaliação formativa

Use uma tarefa curta para verificar compreensão conceitual, execução e capacidade de diagnóstico.

Perspectiva para a formação docente

Ensinar Computação

Na Licenciatura em Computação, o estudante deve aprender a administrar o sistema e também a explicar o raciocínio técnico. Nesta aula, observe:

  • quais conhecimentos prévios os alunos precisam mobilizar;
  • quais erros são conceituais e quais são apenas operacionais;
  • como tornar visível o que acontece internamente no sistema;
  • como avaliar o processo, não apenas o resultado final;
  • como discutir implicações éticas, segurança e responsabilidade.
Pergunta docente: como você ensinaria este conteúdo a uma turma com diferentes níveis de experiência?

Conteúdo essencial

  • O Windows Server oferece funções como Active Directory, DNS, DHCP, arquivos, impressão e virtualização.
  • O Server Manager centraliza instalação de funções e acompanhamento do servidor.
  • O PowerShell permite automação e administração reproduzível por objetos, não apenas texto.

Conceitos-chave

IA e administração responsável

AI
IA no contexto desta aula

Aplicações de IA integradas ao Active Directory devem usar contas de serviço com privilégio mínimo e trilhas de auditoria.

  • Valide saídas e comandos antes de aplicar.
  • Não envie credenciais, dados pessoais ou logs sensíveis sem tratamento.
  • Mantenha rastreabilidade entre sugestão, decisão humana e execução.

Caso aplicado: sistema Web

Arquitetura aplicada

IIS, serviços de arquivo e autenticação integrada são comuns em ambientes corporativos Web. PowerShell permite inventário e configuração repetível.

Cliente→Web/API→Dados

Procedimento recomendado

  1. Identifique o objetivo e o estado atual do sistema.
  2. Faça backup ou snapshot antes de mudanças relevantes.
  3. Execute uma alteração por vez e valide o resultado.
  4. Consulte logs e mensagens de erro antes de tentar outra correção.
  5. Documente comandos, arquivos modificados e evidências.

Comandos e exemplos

Get-ComputerInfo
Get-NetIPAddress
Get-Service
Get-WinEvent -LogName System -MaxEvents 20
Get-WindowsFeature

Erros comuns

  • Executar comandos administrativos sem compreender o impacto.
  • Alterar vários parâmetros ao mesmo tempo e perder a causa da falha.
  • Ignorar logs, permissões, portas ou dependências.
  • Não registrar a configuração anterior e não possuir retorno.

Laboratório avançado

Gere com PowerShell um relatório de serviços, portas, eventos, atualizações e contas usadas por uma aplicação.

Planejar›Implementar›Medir›Explicar

Evidência mínima: diagrama, comandos/configurações, testes, logs e análise crítica.

Prática guiada

Liste informações do servidor, endereço IP, serviços em execução e últimos eventos do sistema usando PowerShell.

  1. Prepare o ambiente e registre o estado inicial.
  2. Execute a tarefa proposta.
  3. Valide com pelo menos dois comandos ou testes.
  4. Capture evidências e escreva uma conclusão curta.

Entrega: relatório curto com objetivo, comandos, evidências, resultado e dificuldades.
