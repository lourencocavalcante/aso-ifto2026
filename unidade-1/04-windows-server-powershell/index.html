04. Windows Server e PowerShell

Conhecer funções de servidor no Windows e executar tarefas básicas com PowerShell.

Por que estudar este assunto?

Muitas instituições utilizam Windows Server para autenticação, arquivos, impressão, DNS e aplicações. O PowerShell permite administrar esses recursos com comandos reproduzíveis.

O que você vai aprender

✓ Reconhecer funções e recursos do Windows Server
✓ Compreender o papel do Server Manager
✓ Executar comandos básicos no PowerShell
✓ Consultar serviços e eventos

Conceitos fundamentais

Role

Função principal, como DNS, DHCP ou File Services.

Feature

Componente complementar instalado no sistema.

PowerShell

Shell e linguagem de automação orientada a objetos.

Service

Programa executado em segundo plano.

Event Log

Registro de eventos do sistema e aplicações.

Active Directory

Serviço de identidade, autenticação e organização de recursos.

Explicação passo a passo

O Server Manager apresenta uma visão gráfica do servidor e instala funções. O PowerShell permite repetir as mesmas tarefas por comandos.

Diferentemente de shells baseados apenas em texto, o PowerShell trabalha com objetos. Isso facilita selecionar propriedades, filtrar e exportar resultados.

Logs de eventos devem ser consultados antes de reiniciar serviços ou alterar configurações.

Demonstração no terminal

  1. Abra o PowerShellUse uma sessão administrativa quando necessário.
  2. Consulte o sistemaExecute `Get-ComputerInfo`.
  3. Veja a redeUse `Get-NetIPAddress`.
  4. Analise serviçosListe todos e filtre os que estão em execução.
  5. Consulte eventosVerifique avisos e erros recentes.

Prática guiada

Produza um relatório PowerShell contendo nome do computador, IP, versão do sistema, serviços em execução e cinco eventos recentes.
