Guia de comandos

Consulta rápida para o laboratório.

Sistema

hostnamectl
uptime
free -h
df -h
lsblk -f

Rede

ip -br a
ip route
ss -lntup
resolvectl query dominio
curl -I URL

Serviços e logs

systemctl status SERVICO
systemctl restart SERVICO
systemctl --failed
journalctl -u SERVICO --since today
journalctl -p err -b

Arquivos e permissões

find CAMINHO -type f
grep -Rni TERMO CAMINHO
chmod 750 CAMINHO
chown USUARIO:GRUPO CAMINHO
