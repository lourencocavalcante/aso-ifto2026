Solução exemplo — Diagnóstico de serviço

Investigar um serviço Nginx com falha de configuração.

!

Use apenas como referência

Esta solução não deve ser copiada, reproduzida integralmente ou entregue como trabalho próprio. Primeiro execute a prática sem consultar esta página. Depois, utilize o exemplo somente para comparar decisões, corrigir erros e compreender etapas que não ficaram claras.

O seu ambiente, comandos, evidências e explicações devem ser produzidos por você.

Ambiente no VirtualBox para Windows

  • Ubuntu Server com Nginx instalado.
  • Snapshot antes da prática.
Windows→VirtualBox→Servidor↔Cliente

Passo a passo detalhado

  1. Instalar e validar

    Instale Nginx e confirme que funciona.

  2. Criar falha controlada

    Faça backup da configuração e adicione uma diretiva inválida em um arquivo de site.

  3. Recarregar

    Execute `nginx -t` antes de reiniciar e observe o erro.

  4. Consultar status

    Use `systemctl status nginx`.

  5. Consultar logs

    Use `journalctl -u nginx -n 50`.

  6. Corrigir

    Restaure a configuração, valide e recarregue.

Comandos de referência

Terminal
sudo apt install nginx -y
sudo cp -a /etc/nginx/nginx.conf /etc/nginx/nginx.conf.bak
sudo nginx -t
systemctl status nginx --no-pager
journalctl -u nginx -n 50 --no-pager
sudo cp -a /etc/nginx/nginx.conf.bak /etc/nginx/nginx.conf
sudo nginx -t
sudo systemctl reload nginx

Como validar

  • A falha foi identificada antes de reiniciar.
  • O log confirma a causa.
  • A configuração foi restaurada.
  • O site volta a responder.

Erros comuns

  • Reiniciar repetidamente sem ler a mensagem.
  • Editar sem backup.
  • Usar KILL no processo principal.
  • Não validar com `nginx -t`.
