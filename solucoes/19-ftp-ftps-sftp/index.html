Solução exemplo — Entrega por SFTP

Criar uma área restrita para envio de arquivos.

!

Use apenas como referência

Esta solução não deve ser copiada, reproduzida integralmente ou entregue como trabalho próprio. Primeiro execute a prática sem consultar esta página. Depois, utilize o exemplo somente para comparar decisões, corrigir erros e compreender etapas que não ficaram claras.

O seu ambiente, comandos, evidências e explicações devem ser produzidos por você.

Ambiente no VirtualBox para Windows

  • Ubuntu Server com SSH.
  • Cliente Windows usando `sftp` no Windows Terminal.
Windows→VirtualBox→Servidor↔Cliente

Passo a passo detalhado

  1. Criar grupo

    Crie `sftpusers`.

  2. Criar usuário

    Crie `entrega01` sem privilégios administrativos.

  3. Preparar diretórios

    Crie estrutura de chroot com dono root e subpasta gravável pelo usuário.

  4. Configurar sshd

    Adicione bloco `Match Group sftpusers` com `ChrootDirectory` e `ForceCommand internal-sftp`.

  5. Validar

    Execute `sshd -t` antes de recarregar.

  6. Conectar pelo Windows

    Use `sftp entrega01@IP`.

  7. Enviar e verificar

    Use `put`, depois compare SHA-256.

Comandos de referência

Terminal
sudo groupadd sftpusers
sudo useradd -m -G sftpusers entrega01
sudo passwd entrega01
sudo mkdir -p /sftp/entrega01/arquivos
sudo chown root:root /sftp/entrega01
sudo chmod 755 /sftp/entrega01
sudo chown entrega01:sftpusers /sftp/entrega01/arquivos
sudo sshd -t
sftp entrega01@IP_DO_SERVIDOR
sha256sum arquivo.pdf

Como validar

  • O usuário entra somente no ambiente restrito.
  • Ele grava na subpasta permitida.
  • Não acessa `/etc` ou outros diretórios.
  • Checksums coincidem.

Erros comuns

  • Dar propriedade do diretório raiz do chroot ao usuário.
  • Não validar sshd.
  • Usar conta administrativa para entrega.
  • Ignorar integridade do arquivo.
