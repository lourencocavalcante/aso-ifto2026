05. Terminal, shell e sistemas de ajuda

Aprender a estrutura dos comandos e descobrir como usá-los sem depender de memorização.

Por que estudar este assunto?

Administradores não decoram todos os comandos. Eles aprendem a interpretar sintaxe, consultar documentação e testar com segurança.

O que você vai aprender

✓ Entender programa, opção e argumento
✓ Usar manuais e ajuda integrada
✓ Interpretar o código de saída
✓ Reconhecer comandos internos e externos

Conceitos fundamentais

Terminal

Interface na qual o usuário digita comandos.

Shell

Programa que interpreta os comandos.

Opção

Modifica o comportamento do programa.

Argumento

Valor ou caminho utilizado pelo comando.

Código de saída

Número que indica sucesso ou falha.

Comando interno

Comando implementado pelo próprio shell.

Explicação passo a passo

A estrutura comum é `comando [opções] [argumentos]`. Os colchetes em manuais indicam elementos opcionais; não devem ser digitados.

O comando `man` apresenta descrição completa. `--help` costuma mostrar um resumo. `type` informa se o nome é comando interno, alias ou programa.

O código de saída zero normalmente significa sucesso. Valores diferentes indicam algum tipo de erro.

Demonstração no terminal

  1. Leia a ajudaAbra `man ls` e procure a opção `-a`.
  2. CompareExecute `ls --help` e localize a mesma opção.
  3. Identifique o tipoUse `type cd`, `type ls` e `type echo`.
  4. Teste erro e sucessoExecute um comando válido e outro com arquivo inexistente; compare `echo $?`.

Prática guiada

Escolha cinco comandos e crie uma ficha com função, sintaxe, duas opções, exemplo e código de saída.

O que entregar

  • Objetivo da prática.
  • Comandos utilizados.
  • Capturas ou trechos de saída.
  • Explicação curta do resultado.

IA relacionada a esta aula

IA

Uma IA pode explicar comandos, mas pode inventar opções ou ignorar diferenças entre versões. Sempre confirme a sugestão em `man`, `--help` ou documentação oficial.
