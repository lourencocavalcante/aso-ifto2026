07. Pipes, redirecionamentos e busca

Combinar comandos para localizar informações e produzir relatórios.

Por que estudar este assunto?

Em servidores há muitos arquivos, processos e registros. Em vez de analisar tudo manualmente, o administrador combina pequenos comandos.

O que você vai aprender

✓ Compreender entrada e saída padrão
✓ Usar pipe para encadear comandos
✓ Redirecionar saída e erros
✓ Localizar arquivos por critérios

Conceitos fundamentais

stdin

Entrada padrão usada pelo programa.

stdout

Saída normal produzida pelo programa.

stderr

Canal separado para mensagens de erro.

Pipe |

Envia a saída de um programa para outro.

Redirecionamento >

Grava a saída substituindo o arquivo.

find

Localiza arquivos por nome, tipo, tamanho ou data.

Explicação passo a passo

O pipe evita arquivos temporários e permite formar uma linha de processamento.

`>` substitui o arquivo; `>>` acrescenta ao final. `2>` redireciona apenas erros.

O comando `find` deve receber um ponto inicial e critérios claros. Buscar em todo o sistema pode ser demorado e produzir erros de permissão.

Comandos desta aula

ComandoPara que serve
ps aux | grep nginxFiltra processos que contêm nginx.
du -sh /var/* 2>/dev/null | sort -hOrdena uso de espaço e oculta erros de permissão.
find /var/log -type f -name '*.log'Localiza arquivos de log.
find . -type f -mtime -7Localiza arquivos alterados nos últimos sete dias.

Demonstração no terminal

  1. Liste processosExecute `ps aux`.
  2. FiltreAcrescente `| grep ssh`.
  3. Localize logsUse `find /var/log -type f -name '*.log'`.
  4. Crie relatórioRedirecione o resultado para `logs-encontrados.txt`.
  5. Confira errosExecute uma busca sem permissão e redirecione `2>`.

Prática guiada

Encontre os dez maiores arquivos dentro de `/var`, salve o relatório e explique o significado de cada coluna.

IA relacionada a esta aula

IA

Antes de enviar logs para uma IA, o administrador pode usar pipes para reduzir o volume e remover IPs, nomes e tokens. Minimizar dados é uma prática de segurança.
