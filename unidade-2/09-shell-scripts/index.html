09. Shell scripts

Criar scripts simples, seguros e reutilizáveis.

Objetivos

  • Criar scripts simples, seguros e reutilizáveis.

Conteúdo essencial

  • Script reúne comandos em um arquivo executável.
  • Use variáveis, testes e códigos de saída.
  • set -euo pipefail reduz falhas silenciosas.

Referência rápida

ElementoExemplo
Shebang#!/usr/bin/env bash
Variávelnome="servidor"
Teste[[ -f arquivo ]]
Saídaexit 0

Comandos

chmod +x script.sh
bash -n script.sh
./script.sh
echo $?

Prática rápida

Crie um script que registre hostname, data, disco e memória em relatório.

Desafio

Adicione validação de diretório e mensagem de erro clara.

Entrega

Script executável e arquivo produzido.
