09. Introdução a Shell Scripts

Transformar uma sequência de comandos em um programa simples e reutilizável.

Por que estudar este assunto?

Repetir manualmente as mesmas verificações aumenta o risco de esquecimento. Um script registra o procedimento e permite executá-lo sempre da mesma maneira.

O que você vai aprender

✓ Criar e executar um script
✓ Usar variáveis e argumentos
✓ Aplicar condições e laços
✓ Registrar erros e resultados

Conceitos fundamentais

Shebang

Linha que informa qual interpretador executará o script.

Variável

Nome associado a um valor.

Argumento

Valor fornecido ao iniciar o script.

Condição

Escolhe um caminho com base em um teste.

Laço

Repete um bloco de comandos.

Função

Agrupa uma tarefa reutilizável.

Explicação passo a passo

Um script começa com `#!/usr/bin/env bash`. Depois, os comandos são organizados em uma sequência lógica.

`set -euo pipefail` ajuda a interromper o script diante de erros, variáveis inexistentes ou falhas em pipes.

Scripts administrativos devem verificar entradas e informar claramente o que fizeram.

Comandos desta aula

ComandoPara que serve
#!/usr/bin/env bashDefine Bash como interpretador.
set -euo pipefailAtiva verificações de segurança.
NOME="${1:-servidor}"Obtém o primeiro argumento ou usa um padrão.
if [[ -f "$1" ]]; then echo "existe"; fiTesta se um arquivo existe.
for ARQ in /var/log/*.log; do echo "$ARQ"; donePercorre arquivos de log.
Terminal
#!/usr/bin/env bash
set -euo pipefail
NOME="${1:-servidor}"
if [[ -f "$1" ]]; then echo "existe"; fi
for ARQ in /var/log/*.log; do echo "$ARQ"; done

Demonstração no terminal

  1. Crie o arquivoUse `nano relatorio.sh`.
  2. Adicione o shebangInsira a linha do Bash.
  3. Inclua comandosAdicione hostname, uptime, memória e disco.
  4. Torne executávelExecute `chmod +x relatorio.sh`.
  5. TesteExecute `./relatorio.sh` e verifique o código de saída.

Prática guiada

Crie um script que gere um relatório do servidor com data, hostname, IP, memória, disco e serviços falhos.

O que entregar

  • Objetivo da prática.
  • Comandos utilizados.
  • Capturas ou trechos de saída.
  • Explicação curta do resultado.

IA relacionada a esta aula

IA

Um script pode consumir uma API de IA para resumir eventos, mas deve tratar indisponibilidade, limite de requisições e respostas inválidas. Nunca coloque chaves de API diretamente no código publicado.
