08. Processamento de arquivos de texto

Usar filtros para extrair informações de configurações e logs.

Por que estudar este assunto?

No Linux, muitas configurações e registros são textos. Saber filtrar linhas e colunas permite compreender rapidamente o estado do servidor.

O que você vai aprender

✓ Pesquisar padrões com grep
✓ Selecionar colunas com cut
✓ Ordenar e contar ocorrências
✓ Introduzir awk e sed

Conceitos fundamentais

grep

Seleciona linhas que correspondem a um padrão.

cut

Extrai campos ou posições.

sort

Ordena linhas.

uniq

Agrupa linhas repetidas adjacentes.

awk

Processa registros e campos.

sed

Transforma texto em fluxo.

Explicação passo a passo

Um log Web pode registrar endereço, data, método, rota e código HTTP. Com filtros, é possível contar erros ou identificar rotas mais acessadas.

`uniq` normalmente deve receber dados ordenados. Por isso, a combinação comum é `sort | uniq -c`.

Expressões regulares ampliam o poder dos filtros, mas devem ser construídas e testadas gradualmente.

Comandos desta aula

ComandoPara que serve
grep -i 'error' arquivo.logSeleciona linhas com error ignorando maiúsculas.
cut -d: -f1 /etc/passwdExtrai o primeiro campo separado por dois-pontos.
sort acessos.txt | uniq -c | sort -nrConta ocorrências e ordena da maior para a menor.
awk -F: '{print $1, $3}' /etc/passwdMostra login e UID.
sed 's/antigo/novo/g' arquivoSubstitui todas as ocorrências na saída.

Demonstração no terminal

  1. Veja usuáriosExecute `cat /etc/passwd`.
  2. Extraia loginsUse `cut -d: -f1 /etc/passwd`.
  3. Mostre UIDUse `awk -F: '{print $1,$3}' /etc/passwd`.
  4. Filtre contas humanasPesquise UIDs maiores ou iguais a 1000 com awk.
  5. Salve relatórioRedirecione a saída para um arquivo.

Prática guiada

Crie um relatório com login, UID, diretório pessoal e shell dos usuários locais.

IA relacionada a esta aula

IA

Uma IA pode ajudar a interpretar um resumo de log, mas os números devem ser produzidos por comandos verificáveis. A análise automática não substitui o registro original.
