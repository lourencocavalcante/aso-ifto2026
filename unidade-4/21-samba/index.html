21. Servidor de arquivos Samba

Compartilhar arquivos com clientes Windows e Linux usando SMB.

Por que estudar este assunto?

Laboratórios e setores administrativos frequentemente usam Windows. O Samba permite que um servidor Linux ofereça pastas acessíveis pelo Explorador de Arquivos.

O que você vai aprender

✓ Compreender compartilhamentos SMB
✓ Instalar e validar o Samba
✓ Criar usuários e grupos
✓ Combinar permissões do Samba e do Linux

Conceitos fundamentais

SMB/CIFS

Protocolo de compartilhamento usado principalmente no Windows.

Share

Pasta publicada.

smb.conf

Arquivo principal de configuração.

smbpasswd

Gerencia credenciais locais do Samba.

testparm

Valida a configuração.

ACL

Permissões mais detalhadas.

Explicação passo a passo

O Samba controla acesso no nível do compartilhamento, mas o Linux também verifica as permissões do diretório.

Um usuário precisa existir no Linux e ser adicionado à base do Samba quando usada autenticação local.

Execute `testparm` antes de reiniciar para evitar que erro de sintaxe derrube o serviço.

Comandos desta aula

ComandoPara que serve
sudo apt install sambaInstala o Samba.
testparmValida smb.conf.
sudo smbpasswd -a usuarioAdiciona credencial.
smbclient -L //servidor -U usuarioLista compartilhamentos.
sudo systemctl restart smbdReinicia o serviço.
journalctl -u smbdConsulta logs.
