18. Servidor Web

Publicar páginas, entender requisições HTTP e consultar logs.

Por que estudar este assunto?

Esta própria plataforma da disciplina é acessada por um servidor Web. O navegador solicita arquivos; o servidor localiza, responde e registra o acesso.

O que você vai aprender

✓ Compreender HTTP e códigos de resposta
✓ Instalar Nginx ou Apache
✓ Publicar conteúdo estático
✓ Consultar configuração e logs

Conceitos fundamentais

HTTP

Protocolo de comunicação da Web.

Requisição

Mensagem enviada pelo cliente.

Resposta

Mensagem devolvida pelo servidor.

Document root

Diretório publicado.

Virtual host

Configuração de um site.

TLS/HTTPS

Proteção criptográfica da comunicação.

Explicação passo a passo

Uma requisição contém método, caminho e cabeçalhos. A resposta contém código, cabeçalhos e conteúdo.

Códigos 2xx indicam sucesso; 3xx redirecionamento; 4xx problema do cliente; 5xx problema do servidor.

Antes de recarregar a configuração do Nginx, use `nginx -t` para detectar erros.

Comandos desta aula

Demonstração no terminal

  1. Instale e iniciePrepare o Nginx.
  2. Teste localmenteUse curl.
  3. Abra no navegadorAcesse pelo IP da VM.
  4. Edite a páginaAltere `/var/www/html/index.html`.
  5. Observe o logAtualize o navegador e veja a nova linha.
  6. Simule erro 404Acesse um caminho inexistente.

IA relacionada a esta aula

IA

Uma aplicação Web pode encaminhar requisições para uma API de IA. O servidor deve aplicar autenticação, limites, timeout e registro de uso para evitar abuso.
