18. Servidor Web

Instalar servidor Web, publicar site e analisar logs.

Objetivos

  • Instalar servidor Web, publicar site e analisar logs.

Conteúdo essencial

  • Servidor Web responde a requisições HTTP/HTTPS.
  • Virtual hosts separam sites por nome.
  • Configuração deve ser validada antes de recarregar o serviço.

Referência rápida

ElementoExemplo
document root/var/www/site
configuração/etc/nginx/sites-available
log de acessoaccess.log
log de erroerror.log

Comandos

sudo apt install -y nginx
systemctl status nginx
nginx -t
curl -I http://localhost
tail -f /var/log/nginx/access.log

Prática rápida

Publique uma página com nome da equipe e valide por curl e navegador.

Desafio

Crie um virtual host por nome e uma página de erro própria.

Entrega

URL, configuração, teste e trecho de log.
