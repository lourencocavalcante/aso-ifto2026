# ASO IFTO 2026

Site estático completo da disciplina Administração de Sistemas Operacionais.

Publique todo o conteúdo deste diretório na raiz do repositório `aso-ifto2026`.

## Recursos
- interface inspirada no Windows;
- menu lateral responsivo e estável;
- 22 aulas ampliadas;
- modo apresentação em tela cheia;
- navegação por setas, Page Up, Page Down e espaço;
- busca, tema escuro, cópia de comandos e progresso local.
