# ASO IFTO 2026 — Licenciatura em Computação

Projeto estático completo para a disciplina Administração de Sistemas Operacionais.

## Características
- interface inspirada no Windows, sem controles decorativos de janela;
- página exclusiva do professor;
- 22 aulas alinhadas à ementa fornecida;
- sequência didática voltada à Licenciatura em Computação;
- teoria, demonstração, prática, diagnóstico e avaliação formativa;
- sistemas Web e IA contextualizados nos módulos;
- bibliografia básica e complementar fiel ao plano;
- modo apresentação, pesquisa, tema escuro e progresso local.

Publique o conteúdo diretamente na raiz do repositório `aso-ifto2026`.
