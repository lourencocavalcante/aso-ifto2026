# ASO IFTO 2026 — Plataforma Acadêmica

Projeto estático completo da disciplina Administração de Sistemas Operacionais.

## Destaques
- interface premium inspirada em sistemas de laptop da Apple, sem copiar marcas;
- navegação lateral translúcida e responsiva;
- 22 aulas com conteúdo técnico ampliado;
- casos de sistemas Web em todas as aulas;
- IA contextualizada em todos os módulos, com segurança, governança e validação humana;
- laboratórios avançados, discussões e evidências;
- modo apresentação em tela cheia;
- busca, tema escuro, progresso local e cópia de comandos.

Publique todo o conteúdo deste diretório na raiz do repositório `aso-ifto2026`.
