Projeto final

Implantar e documentar um servidor de laboratório com serviços básicos.

Cenário

Uma instituição precisa de um servidor Linux para publicar uma página Web, compartilhar arquivos, receber entregas seguras e manter uma rotina de backup.

Requisitos

  1. Linux Server atualizado com IP estático e hostname.
  2. Acesso SSH por chave e firewall.
  3. Servidor Web com página da equipe.
  4. Um compartilhamento NFS ou Samba.
  5. Transferência por SFTP.
  6. Usuários, grupos e permissões adequados.
  7. Monitoramento básico e backup com restauração testada.

Entrega

  • Diagrama da arquitetura.
  • Inventário do servidor.
  • Comandos e arquivos alterados.
  • Testes de funcionamento e segurança.
  • Procedimento de backup e restauração.
  • Apresentação prática do ambiente.
